# T01–T45 本轮验收矩阵

版本：0.19.0-collaboration.2；基线：FIRST_RELEASE_SPEC 第 11 节及第 12.13 节。此表是验证覆盖和限制，不是“45 项已通过”的声明。

标记：A＝可执行自动测试；L＝生产协议／RPC／本地 Git 与受控后端回环；M＝真实 Codex；P＝实际 Windows 打包进程；UI＝实际 React 界面配合界面夹具。MySQL 是本机隔离 5.7.18。它们不能相互替代。

**用户确认目前只有一台电脑，因此所有需要两台物理电脑、公网、真实 GitHub 仓库或正在使用的 Codex 桌面交接的最终验收仍待进行。**
