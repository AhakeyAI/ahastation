- 双击 [station-unified-meeting.html](station-unified-meeting.html) 用浏览器打开，无需安装 Node、Python 或连接服务器。
- [原型源片段](station-unified-meeting.fragment.html) 用于继续修改；完整 HTML 已包含运行样式和交互。

建议路线：邀请设备 → 发送示例目标 → 审阅可读计划并选择设备 → 批准、分配 → 顶部推进演示进度 → 切换会议／任务 → 查看成果与测试。还可以切换电脑视角、B 断线、任务停止／明确继续，以及已有 Codex 对话接续。

本次修订：聊天改为群聊，删除发言目标下拉框，输入 @ 或点击“@ 点名”选择已参会的 Host、设备执行 Agent 或原生对话；支持上下键、Enter／Tab 选择与 Esc 关闭。设置收敛为账号与本机、GitHub、仓库与本机目录三个可展开区域。都是模拟操作，不要填写真实密码。更改目录／仓库后须重新确认本机授权。

后续 Q86–Q100 已确认自动复用 Agent 登录、无任务也可交流、首页新建先选项目／Host、B 先加入后按需绑定、原生历史按摘要／引用分享、新参会者按需背景、主项目切换隔离、成员身份稳定与独立任务上下文、群聊明确关联任务补充、共享中断范围及保留独立专家交流。当前 HTML 尚未按这些确认更新，尤其没有首页创建步骤；它是上一轮交互草图，不能视为最新完整流程。最新权威需求第 12.13 节有统一主题清单，实施方案见上方链接。本轮只更新说明，未重新渲染或复测 HTML。

所有连接、任务、测试、文件、提交和 PR 都是示例。原型不会访问真实 Hub／模型／GitHub，不会操作本机项目或生成正式交付。A 始终在线，仅演示 B 的网络断线；原型通过不代表生产功能已实现或双机验收通过。

原型核验：[INTERACTION_CHECKS.json](INTERACTION_CHECKS.json)。使用实际 Chrome 无头浏览器检查 12 组交互／布局，全部通过，脚本错误 0；包含 1024／736／390／320 像素宽度与浅／深色显示。这些记录只证明本 HTML 的演示交互，不是 Station 生产测试结果。[原功能保护审查](../UNRELATED_FUNCTIONS_AUDIT.md) 记录真实源码发现与定向产品回归，未把原型当作实现完成。
