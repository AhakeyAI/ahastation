## 每项实施卡必须包含的内容

实施卡包含 WBS ID、实际 owner、源与目标 SHA、前置证据链接、输入输出、允许修改的模块、验收命令、实际结果、遗留风险和回滚方式。记录状态为待开始、进行中、待验收、通过或阻塞；“代码存在”和“mock 通过”不能直接改为通过。

T01 的最小契约应明确：Charter 确认只对指定版本有效；Run 记录 backend/nativeSessionId/attempt/sourceRevision/授权及合同 hash；Decision 的 resolved/expired/revoked 不可重复应用；Evidence 区分自动结果、待人工和未知；Acceptance 记录用户对哪个 candidate 的接受。观察身份仍保留 `hash(clientKind + nativeSessionId + cwd)`，另建 Task 身份与可撤销关联，不能替换旧 ID 后丢失索引。

迁移与恢复必须先有备份和 schemaVersion，重复导入不能重复创建 Task 或启动 Run。无可靠映射时保留为待关联观察对象。恢复后显示 interrupted/pending，写操作必须重新检查授权。
