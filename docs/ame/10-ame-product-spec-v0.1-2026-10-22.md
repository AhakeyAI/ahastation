## 产品与使用对象

AhaStudio 是 Agent Meeting Environment。用户主要与一个长期助理说出目标、取舍和反馈，助理主持讨论、组织专家，将决定转成持续推进且可以验收的工作。用户不必逐个配置 Worker、选择每次调用的模型或守着终端。

AhaStation 是承载这支 Agent 团队的随身第二台电脑，方向为 Your agent computer, anywhere。软件可运行在用户已有电脑上。首发聚焦研发、设计讨论、研究、文档和交付，首批项目基于 GitHub；通用分析可做，完整生活事务执行不在首发范围。人群分为已有固定 Agent 主机的软件用户，以及需要携带个人项目环境的新购设备用户，两者购买动机分别验证。

首发主平台为 Windows x64，首次公开可用闭环必须覆盖 macOS Apple Silicon。两端支持经验证的 Harness 和任务，不承诺所有模型、工具与平台能力相同。硬件现状为 N5095、16GB、512GB、DC12V、内置麦克风和扬声器，现有纯电续航由用户提供为 2–3 小时；新增上网棒和实体按键板后的能力须真机验证。

最新语音约束：用户确认樱桃 SDK 不支持 N5095，支持范围为 Core Gen11–14／Core Ultra；现有硬件不能依赖它完成首发语音。替代本地模型或 API 必须按两端、多音色、打断和真实噪声验证，不降低每专家独立音色要求。官网 ISV 应用仅作支持 CPU 上的体验来源，内部 demo 未获得外发条件。

## 团队组织与会议

长期助理始终是用户主要入口和会议 Host。普通项目由助理兼任项目经理，复杂项目再委派独立经理；项目协调责任唯一。产品、设计、运营、前端、后端、测试等专家以“职能＋名字”展示，职能负责人可派项目执行子 Agent，结果回到负责人，再由经理和助理汇总。

默认用户与助理双人会议。Host 可简短说明后直接邀请项目内已有专家，用户可阻止或点名。每位专家首发具有独立音色；同一时刻只有一位 Agent 播报，专家先向 Host 示意，再按顺序发言。用户按语音键立即打断播报并录音，打断不等于停止执行。明确越权、数据破坏风险或无法满足既定验收时，成员直接上报并暂停受影响任务，不等待发言；独立任务继续。

专家按需调用，不逐轮调用全体模型。“在会”与“已审阅”分别展示。入会提供议题、确认目标、约束及原话／文档／任务版本引用；专家可按权限回查，不能只依赖 Host 摘要。其他项目私有内容不自动带入。

首发角色使用稳定头像及轻量状态动效，突出说话、录音、思考、执行和待决定状态；用户可修改名字和头像，每位专家保持独立音色。手持与外屏优先呈现任务、材料和成果，复杂 3D 形象及口型同步后置。

## 用户主流程

1. 安装并连接自己的 AI 服务，设置本机名称、允许目录与执行能力。单机不要求 Aha 账号，跨设备协同时登录。引导询问外部应用权限和是否开启自动优化；自动优化初始关闭。
2. 进入助理双人会议，共享区默认看板，项目筛选默认全部。按语音键后锁定本轮项目、接收对象和共享引用；项目不明确先保存并澄清，不派工。
3. 新接入已有项目时先只读调查 README、规范、架构、Issue、分支与未提交改动。大型项目按目标渐进深入，复用现有计划；构建、安装或写入另按授权。
4. 会中区分讨论、假设、决定、待确认项和工作项，自动创建或更新 TODO。记录不等于授权执行。待设计通过 grill 对齐产品、技术和 UX；重要界面或流程先看关键界面、可点击原型或演示，小修复不强制原型。
5. 当前阶段目标、范围与非目标、必要方案、可检查验收、权限、额度及阻塞问题明确后，助理主动收敛，复述唯一带版本安排，请用户自然语言或点击确认。复杂项目分阶段确认，非阻塞问题记录后推进。
6. 项目经理在项目获分配额度内选择职能、模型和 Worker，用户手动指定执行设备；隔离工作区运行。Host 汇总进展、决定和异常，不要求用户监看每个会话。
7. 交付先经独立会话复核，固定原始需求、验收条件和成果版本，回传证据。必修问题返工，非阻断建议另建后续任务，必验项无法判断时不能自动通过。
8. 用户可接受结果、接受并合入、继续修改或稍后处理。接受不自动合并；合并、推送、部署与发布分别按授权处理。满足该工作项约定的终点并由用户接受，才显示已完成。

技术方案普通、可逆的选择由团队沿项目规范自主决定并留记录；明显影响体验、费用、数据、长期维护或难回退的选择，用用户能理解的选项确认。结束会议后已授权工作继续，未确认安排留草稿，待决定保留，麦克风关闭。

## 看板与项目节奏

| 设计项 | 首发规则 |
| --- | --- |
| 主层粒度 | Issue、Story 或 WBS 工作包的业务工作粒度，不拆到每个开发点；详情展开执行子任务 |
| 两个维度 | 需求结构与职能负责人承担工作，基于同一份任务记录 |
| 视图 | 泳道看板、甘特图；默认全部项目，可按项目筛选 |
| 大阶段 | 待设计 → 待执行 → 执行中 → 测试中 → 已完成 |
| 细分状态 | 阶段内表达阻塞、暂停、失败、状态未知、待接受及提交／合并／发布进展；后几种分别依据真实证据，不推导为同一件事 |
| 完成门槛 | 必需子任务完成后仍需整体验证、达到约定终点和用户接受；内部子任务无需用户逐项验收，但保留独立复核 |
| 时间 | 计划、预计和实际分别记录；预计延期不改写原计划，无排期显示未排期 |
| GitHub | 主工作项关联 Issue；细分子任务默认在 AhaStudio，明确要求或项目设置后再创建对应 Issue／子 Issue；默认不自动关闭 Issue |

每项目选择里程碑持续推进或 Scrum Sprint，助理协助设置。Sprint 默认两周，可在设置或通过对话修改；里程碑模式不强制固定周期。Sprint 维护本轮目标、计划、进展检视、评审和回顾，Agent 在授权内持续执行。到期按期结束，保留未完成原因和原属迭代，下一轮安排由用户确认。原授权预算内工作可继续，不自动扩额或延长 Sprint。

## 语音与共享工具

短按一次开始、再次短按发送并闭麦；长按录音、松手发送并闭麦。结束本轮输入不结束会议。共享对象及选区在录音开始锁定，切视图不偷偷更换语音对象。用户阅读、滚动或编辑时保持其位置，助理切换展示先提示。后台默认提醒后收听，活动对话直接回答，主动播报按用户设置。

普通进展进入群聊和看板并合并汇报，不逐条弹通知；团队能自行解决的问题先内部处理，需要用户决定、额度不足或无法继续时再提醒。明确越权和数据风险先暂停相关执行再通知；用户可设专注时段，具体跨端去重及静音表现通过原型验证。

| 表面 | Agent 能力 | 用户交互 |
| --- | --- | --- |
| 内置浏览器 | 通过工具、skill、computer use 操作，默认独立登录空间 | 可接手登录、验证码等；接手时暂停该浏览器自动操作，交还后重新读页面 |
| 文档和 PDF | 通过适配工具生成、修改和预览，格式能力逐项验证 | 支持对象可接管编辑，Agent 暂停修改，交还后先读变更再继续；不承诺所有格式都有完整内置编辑器 |
| CLI | Agent 在授权内执行，展示命令、输出和错误 | 不支持直接接管；人工排查使用原工具或系统终端 |
| 软件外应用 | 需要独立的设备／应用／屏幕及查看或控制权限 | 安装引导设置设备能力，任务时确认，可在可信另一端确认；缺系统授权则暂停，不能虚报成功 |

用户可分别授权读取日常浏览数据、控制日常浏览器，不自动授予另一类权限；浏览登录默认保存在本机，不自动跨端复制。项目完全访问免逐操作批准，但所有模式仍确认阶段计划；完全访问不自动打开外部屏幕或控制权限。

## 额度与执行控制

每项目默认周执行总额度，可改月或日。经理按任务复杂度灵活分配，Worker、重试、验证共享，不通过新阶段、设备或 Worker 重置。额度为主要限制，时间为辅助；原 30 分钟为历史内测值，不作为新版核心预算。每可验收任务默认最多三轮实现到独立复核，包含首次，可由用户调整。

额度按服务分别记金额、真实可读的订阅单位或明确标识的估算用量，不把不同币种、Token、百分比硬相加。按职能和复杂度选模型，用户可设服务优先级与切换阈值；只有服务已连接授权且满足最低能力、数据和权限要求才接力。无合格服务则暂停，不自动降交付标准。实际消耗不可获取时显示未知或估算，精确强制能力须在对应适配器验证。

长期助理协调多项目共享服务余额，高优先级先获未分配额度；已分配额度不自动挪用，调整提案由用户确认。全部已分配执行额度耗尽时暂停，先询问追加，不追加再询问是否新周期继续。项目预算刷新与服务真实额度刷新分别判断。

会议不占执行时长、不设会议费用上限；ASR/TTS 由独立本地模型或 API 提供，不计项目用量。会议触发的实际后台任务仍受执行预算约束；会议模型与执行模型的细分归属在技术验证中明确。

## 多设备与离线

设备统一安装 AhaStudio，内部可含后台服务。用户手动指定设备，本机协调者调度本地 Harness；群聊只突出启动、完成、异常，内部仍需确认、去重、停止和恢复消息。小文档文本可以直接发送群聊或 Agent 私信；代码和大文件经 GitHub 传递明确版本。未提交修改先展示文件范围、确认后通过专用检查点分支交接，保留原目录和主分支，不夹带无关内容。

同项目仅一个正式计划写入主持者，其他端查看或明确接续；不同项目可同时推进。换交互设备不迁移 Run 或重复派工。发起端离线，执行端继续授权阶段并保存结果，新增授权时暂停，用户在可信设备明确接续助理。首发不自动接管全局助理。

断网保留输入，普通消息恢复后补发，改变执行状态的旧指令先核对版本和有效性。远端停止须显示已记录、已送达、执行端确认或状态未知，未确认不能显示已停止。通勤允许安全暂停，不能承诺无网络、电量不足仍持续执行。跨设备群聊、私信和小文档正文仅可信设备解密，官方中转密文；用户选择的 AI 服务接收上下文是另一条路径。

（10-27 更正）实现路线：跨设备以 `etrnal-dev`（collaboration.5）为基础，有条件地部分采用（R1）。内部验收阶段采用受信 Hub + 设备签名，Hub 能看到内容，但不能伪造任何要执行的指令（ADR 0017）。**本节「中转密文」规则不变，是首次公开可用的前置条件。** 首轮内部验收由 macOS 协调、Windows（N5095）执行；双向验收仍是公开可用门槛（ADR 0018）。

首次启用跨设备协同时引导用户保存恢复凭据。有其他可信设备时，由它授权新设备并撤销丢失设备；全部设备丢失时，用恢复凭据恢复仍有备份的加密记录。可信设备与凭据都没有时，可重建环境、从 GitHub 拉取项目，但不承诺恢复旧加密聊天。解密凭据与备份数据存在是两个分别检查的条件。

## 知识 插件与自动优化

正式需求、架构、设计和验收进入项目仓库，关联来源与版本；完整转写、决定、授权和个人偏好存 AhaStudio，原始录音不默认长期保存。记忆区分跨项目用户偏好、通用专业经验和项目专属内容，后者跨项目引用需授权。外部 Issue 或文档变更先展示差异，目标范围验收变化形成提案，不覆盖执行计划；危险时暂停相关工作。

本机文字记录、决定与验收证据默认保留到用户主动删除。临时缓存和普通运行日志可配置自动清理，不连带删除决定与验收证据；需要作为证据的日志片段单独保全。官方中转密文另定保存期限，不承诺永久存储。

首发内置核心插件，支持手动安装第三方插件或 Skill，展示来源、版本与权限，可禁用卸载；公共市场后置。插件化覆盖沟通、记忆、规划、编排和交付，授权、额度、证据与用户停止规则保持可验证。

自动优化首次启动询问，默认关闭。用户开启后，默认没有 Agent 执行、项目仅等人工时可用充裕闲置额度，保留项目后续所需额度；可改为全部任务完成或临近服务额度重置且剩余充裕等更严条件。每轮评估生成及评测消耗，结合在途预留；影响正常项目时保存候选、证据和用量，停止后续优化，正常任务恢复即让位。

候选生成、评测、保存、启用和分享是不同动作。候选须经新案例、历史回放及未参与优化案例检验，用户确认后启用；新任务用新版本，在途任务保留旧版本，仅在明确阶段边界检查后切换。不能自行提高额度、扩大权限或降低验收标准。优化成果默认私有，分享前主动预览确认。

## 开放与服务

完整本地核心免费开源，不绑定硬件；用户自带 AI 服务。官方远程托管先行，最多绑定两设备，试用固定为首次两端成功远程连接后 30 天，显示准确到期时间，可换绑；换绑、重装及重连不重置。首发一个官方远程协同订阅档，超出名额新增绑定需订阅，订阅后不限绑定数，不等于不限其他资源。具体价格与服务并发待托管成本和内测数据后另提方案确认，换绑执行细则继续设计。

到期不启新官方远程阶段，已授权阶段在原预算内可完成验证并回传，停止撤销控制保留，本地核心与已有记录查看导出保留；提示订阅或自托管，自托管尚未发布时明确状态。自托管方案后补。

| 场景 | 必须观察到的结果 |
| --- | --- |
| 一句话安排已有 Issue | 关联现有工作项，保留原话和版本，未确认不写入执行 |
| 语音跨项目歧义 | 先澄清，保留输入，不误派另一个项目 |
| 会中专家补充与反对 | 独立音色、可追溯意见、单人播报，异议不因汇总丢失 |
| 界面需求 | 先展示适当设计产物，再按确认的版本实现 |
| 并行跨设备任务 | 不重派，按真实 Git 版本交接，同一余额不重复分配 |
| 文档接管 | Agent 不覆盖人工编辑，交还后识别变更 |
| 额度阈值与模型切换 | 不超授权分配，能力不足明确暂停；不把估算显示为精确 |
| 独立复核失败或无法判断 | 不能显示完成，用户看见对应证据及下一步 |
| 仅接受但未合并 | 显示接受记录和实际集成状态，不虚报已合并发布 |
| 断网停止与双端决定 | 状态未知诚实呈现，恢复去重，旧批准不重复生效 |
| 自动优化关闭与余量不足 | 关闭无优化调用，开启后先预留，阈值触发保存暂停 |
| 托管到期 | 禁止新远程阶段，允许规定收尾，保留本地使用与记录 |

内测先自举，公开可用前至少三位非开发参与者各完成真实任务，整体覆盖两平台；由用户或团队定向邀请，暂不公开招募，名单可在可安装版本后确定，尽量覆盖固定 Agent 主机、随身项目及不熟悉代码的创造者。允许引导但开发者不代操作。故障阻断标准、目标指标和正式发布日期见确认单，不用三人通过替代长期稳定性证据。
