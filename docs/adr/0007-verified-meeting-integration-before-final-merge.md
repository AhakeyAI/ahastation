# 通过已验证的会议分支放行代码依赖任务

为了让自动任务分配在代码依赖处持续推进，前序成果经 Host 检查后可以整合到会议专用集成分支，组合验证通过后供后续任务使用，无需用户逐个合并成果 PR 才开始后续工作。用户明确允许会议工作分支内的自动整合，但合入主分支或既定最终目标分支仍需其明确批准；任务交付、Host 检查、会议集成、最终合并和用户最终验收分别管理，不能把其中任一步误报为全部完成。该决定将历史 ADR-0001 的已验证会议基线原则用于新的多设备流程并细化访谈 Q28 的合并授权边界，不代表现有本机集成已完成 GitHub 适配；若整合冲突或组合验证失败，则保留最近通过验证的会议版本并暂停受影响的依赖工作，由 Host 在授权范围内安排相关原任务返工，检查和验证通过后再推进。
