# 停止释放执行资源并保留可继续的任务

首版统一使用“停止任务”，不另设表示放弃整个交付的“取消任务”；停止结束该任务的当前执行，只有确认实际停止后才释放执行资源和并发名额，原 Codex 对话、任务记录、工作区文件及提交都保留。停止后由用户明确继续，不因重连或后续补充而自动重启；其他独立任务可以继续，依赖该任务结果的工作等待其继续或重新安排，不要求为了释放资源而放弃或删除任务。这个取舍将业务任务的保留与执行资源占用分开，旧传输层 cancel 不可直接映射为业务任务废弃，尚未核实停止时也不可提前放行资源；桌面旧轮次结束或停止后自动接续已经提交的 Station 指令仍是另一种已确认场景，不因此被取消。
