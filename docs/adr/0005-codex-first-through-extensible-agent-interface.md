# Codex 首版与可验证的多 Agent 扩展接口

首版先在 Windows 双机上完成 Codex 新任务执行与既有原生会话接续两条核心链路，避免同时承诺多个正式 Agent 和平台的全部实机验收。用户同时要求完成多 Agent 统一接口，并至少通过一个不调用模型的测试适配器验证能力声明、跨设备任务接收、事件与结果回传、停止及状态核对的完整流程；不支持的能力必须明确声明，不能用空接口或通用 backendId 代替扩展验证，也不据此宣称其他真实 Agent 已可生产使用。其他正式 Agent 后续通过适配器接入，现有其他 Agent 的本机能力以及 Linux／macOS 兼容结构保留，跨平台实机验收安排在后续阶段。
