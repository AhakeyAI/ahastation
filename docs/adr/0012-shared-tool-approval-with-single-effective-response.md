# 原生工具审批跨端展示并只接受一次有效答复

> 2026-11-02 范围说明：本条讨论跨设备的**用户**审批入口，不等于要求子任务把工具请求交给 Host Agent。新本机原生 Worker 按[当前接线规划](../plans/2026-11-02-native-cli-worker-integration.md)使用 CLI 原生审批；跨端审批不作为本机最小闭环前置，其既有决定不因取消 Host 工具审批而自动删除。

首版将受支持的工具审批同步到两端 Station 并允许任一端答复，同时保留 Codex 桌面的原生审批入口，避免远端任务只能等待用户回到执行电脑处理。各入口答复同一个请求，只有一次有效决定可生效，已处理、过期或不再属于当前执行的请求不得重复放行，且审批不能扩大执行设备的本机授权。工具审批属于已接任务的执行交互，因此协调设备离线时执行设备仍可处理其本机审批；暂不支持的原生交互明确提示回执行设备处理，不能用现有本机审批卡或空回调宣称网络审批链已实现。
