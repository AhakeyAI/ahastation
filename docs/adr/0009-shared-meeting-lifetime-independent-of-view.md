# 共享会议运行独立于查看窗口

主窗口关闭默认转后台并保留连接、Host 和已授权任务运行，返回首页或关闭共享会议标签只暂离查看界面，会议可从列表重新进入，避免视图关闭意外终止跨设备协作。显式退出 Station 才进入本机任务停止流程：提示受影响任务、请求停止并核对结束、保留任务及成果，其他设备已接任务按协调者离线规则继续，不自动关闭 Codex 桌面或停止桌面独立发起的工作。若不能确认停止，应明确显示未确认并由用户选择等待或强退，强退不等于资源已释放或任务已结束，恢复后须先核对原执行；这要求调整当前本机会议 end／清池与短时退出逻辑，不能直接将旧关闭动作复用于共享会议。
