# 以完整交付定义任务边界

用户希望 Codex 围绕一个目标连续完成多文件修改、必要测试和结果说明，因此一个协作任务对应一次完整交付，不把每个修改步骤拆成独立任务；在会议目标最终验收前，同一交付目标的补充和返工仍归原任务并可跨多轮对话，最终验收后的追加或修复则建立关联原成果的后续任务并保留原验收记录。Host 只在工作可独立交付、适合分派给不同设备或 Agent 时拆分；需要并行的独立任务使用独立工作区和分支，不安排两个任务同时写同一个物理目录，非仓库任务可使用独立普通目录并借助用户指定的资料仓库传递文件。首版不默认向同一个 Codex 会话连续安排多个独立任务，相关队列规则留待确有需要时另议；同一原生对话的桌面／Station 执行交接仍保留，单任务停止与继续采用 ADR-0008 的保留任务并释放执行资源原则。
