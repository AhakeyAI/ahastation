# 共享会议保留唯一协调者和初始协调设备

用户希望在任意参会设备上发言、点名和提出或调整任务，同时避免多台电脑各自拆分同一个目标并重复派发，因此每个共享会议保留一个协调者、一份统一计划和调度流程，首版固定由创建会议的电脑承载且不提供手动或自动协调设备移交。其余设备可以操作会议和执行任务，但不各自拥有独立协调权；执行设备只有校验授权、保存任务并确认接收后才算接单，协调设备离线后已接但尚未启动的任务也可在并发和授权条件满足时启动，用户主动停止的任务仍须明确继续。协调设备离线时，新的补充要求和继续请求先保存、等其恢复后再发送，停止请求仍可处理且会议外独立使用本机 Codex 桌面不受限制；不为点名原生会话设置新执行绕过，也不启动第二协调者。
