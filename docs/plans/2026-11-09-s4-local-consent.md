# S4 本机待授权目录与扫描显示管理（#104，部分交付）

基于 S2 #145 和 S3 #151，本次实现可独立验证的本机只读流程。#104 保持打开：
Hub 项目授权、G2/P1 视觉验收、S5 收编，以及安全结束原会话均不在此次交付中。

## 用户流程

1. 启动台和本地任务看板均提供扫描管理。首次引导打开原生授权确认和目录选择；
   取消、失败不结束引导。移除原来只播放动画、超时也算扫描完成的行为。
2. 用户明确启用扫描后，使用已有有界路由读取，只提取 Claude/Codex 的会话标识和 cwd。
   未授权目录不做标题/状态解析、Git 项目探测或会话进程关联。没有授权时完全不扫描。
   路由字段可能与首条消息同处一行，因此这是有限元数据读取，并非承诺从不打开历史文件。
3. 排除本机内部会话、IF-2 Worker/Station 和归属未确定的会话。待授权区仅展示规范目录、
   目录名和会话数量，每轮最多 100 个目录；相对路径、不可用目录不产生提醒。
   此时没有 Git 仓库身份，不把目录声明为已识别的独立项目。
4. 系统通知不包含路径、标题或会话 ID；点击后打开启动台并聚焦扫描管理区，不自动授权。
   同一运行期间相同目录不重复提醒，新一批提醒间隔至少 60 秒，记忆最多 1000 项；
   达到上限后保留应用内列表。系统拒绝通知也不影响应用内授权入口。
5. “检查只读授权”只接受主进程最新待授权列表中的键。原生确认默认取消，显示实际目录和范围。
   确认前后校验授权/忽略版本、真实路径、inode/设备号；撤权后再授权也作废旧弹窗。
   同意后只追加该目录的本机只读授权，其他工作树没有隐式权限。
6. 已授权、归属明确的用户/已收编会话可以忽略；待授权目录可以忽略提醒。
   忽略会话从扫描结果和看板移除；忽略目录仅隐藏提醒，不改变现有授权。
   恢复前须再次确认，恢复仍受当前授权限制，不会重新授权已撤销的目录。

## 存储与接口边界

`sessions/scan-access.json` 继续保存本机只读目录授权。忽略偏好另存为
`sessions/scan-preferences.json`，版本 1，只有会话 SHA-1 标识与目录 SHA-256 键；
不存标题、原生 ID、明文目录、正文或执行授权。串行原子替换写入，成功后才更新内存。
每类最多 10000 项、文件不超过 2 MiB；损坏或不可读时暂停扫描，并提供显式重置入口，
即使扫描停用也能重置。忽略偏好既不是 IF-2 登记，也不是项目执行/分享授权。

快照新增可选 `pendingDirectories` 和 `hidden`。preload 新增
`reviewDirectory({key})`、`ignoreDirectory({key})`、`ignoreSession({id})`、`restoreHidden()`
对应 IPC；renderer 方法接收 key/id 字符串，由 preload 包装对象。
IPC 严格校验负载和既有主窗口/已登记项目室窗口策略，不接受 renderer 自造路径。
忽略会话时重新读取 IF-2，防止旧列表把已归为内部的会话当成用户会话。
`onReviewRequested` 只接收主进程通知导航事件，不携带授权或会话内容。

偏好版本变化会作废正在进行的读取；撤权立即清空可见会话、项目分组和待授权目录。
历史文件、会话 ID、项目历史 ID、IF-2 登记和执行/分享授权不会因忽略而改写。
该本机快照不能直接作为 IF-7 跨设备清单；IF-7 v0.2 仍是等待确认的提案。

## 验证

服务与 IPC 测试覆盖授权前仅路由读取、归属过滤、授权后读取、文件哈希不变、
撤权/重新授权竞态、目录替换/链接、忽略/恢复持久化、损坏和写失败、非法负载和来源窗口。
通知控制器验证批次合并、限频、撤权关闭及系统拒绝；浏览器验证取消/错误不越权、
重复点击单次请求、忽略与恢复、实际启动台授权引导、设置聚焦及 800px 布局。
这些自动化不能替代 OS 原生通知和 G2 视觉验收。
