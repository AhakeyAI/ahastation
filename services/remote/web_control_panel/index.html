配对 本机 Agent 导入 Bridge

本机网站控制台

把当前电脑上的 Codex / Claude Code 变成 Linux 小电脑可调用的远程 Agent。

这个网站运行在本机浏览器中，负责扫描本机 Agent、配置待配对 Linux Hub，并一键启动 Desktop Bridge。 默认真实执行；需要只验证链路时，可手动开启 dry-run。
